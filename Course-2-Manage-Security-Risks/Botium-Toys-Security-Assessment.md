# Botium Toys Security Assessment

## Project Overview

This project was completed as part of the Google Cybersecurity Professional Certificate.

The objective was to evaluate Botium Toys' existing security controls, identify compliance gaps, assess risks, and provide recommendations to improve the organization's security posture.

## Security Controls Assessment

| Control | Status |
|---|---|
| Least Privilege | Not Implemented |
| Disaster Recovery Plans | Not Implemented |
| Password Policies | Implemented |
| Separation of Duties | Not Implemented |
| Firewall | Implemented |
| Intrusion Detection System (IDS) | Not Implemented |
| Backups | Not Implemented |
| Antivirus Software | Implemented |
| Encryption | Not Implemented |
| Password Management System | Not Implemented |

## Compliance Assessment

### PCI DSS

Identified risks related to protecting customer payment information, including the need for encryption, stronger access controls, and improved password management practices.

### GDPR

Reviewed requirements related to protecting customer data, breach notification procedures, data classification, and privacy controls.

### SOC Principles

Evaluated access policies, confidentiality, data integrity, and availability considerations.

## Recommendations

Based on the assessment, recommended improvements include:

- Implement encryption for sensitive customer data
- Apply least privilege access controls
- Establish backup and disaster recovery procedures
- Implement intrusion detection capabilities
- Strengthen password policies and password management
- Improve data classification and inventory processes
